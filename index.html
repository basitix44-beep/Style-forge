Describe the website you need

Tell StyleForge the business, audience, pages, mood, colors and key action. It creates an editable starter layout on your canvas.

Without an API key, the local starter generator runs. With a Groq key, StyleForge asks the AI for tailored copy, layout decisions and requested actions such as WhatsApp.
Security: a key entered here is used by this browser and is not saved by StyleForge. Do not use a sensitive production key in a public/shared device. For a public SaaS, use a secure backend proxy.

What gets generated?

• Hero heading and business-specific copy
• Primary call-to-action
• Service/benefit cards
• About and contact blocks
• Suggested page title and SEO description
• Editable, draggable canvas elements

Use Desktop / Tablet / Mobile controls in the main header to check viewport sizes. The editor stores one canvas layout; independent per-breakpoint styling and fluid responsive reflow are a next engineering layer.

A starter library plus reusable sections. Selecting a full starter replaces the current page canvas, so save/export your project first if needed.

Pre-launch checklist

□ Check Desktop, Tablet and Mobile previews
□ Confirm all buttons and links
□ Add image alt text and meaningful headings
□ Add contact details and privacy notice
□ Set title, description and social share image
□ Test exported HTML in a browser
□ Connect real forms / analytics before launch
Audits are recommendations, not a certified WCAG test or a substitute for testing the exported site on real devices.
